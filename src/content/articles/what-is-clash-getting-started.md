Clash 系（包括 Clash Verge、Clash for Windows 的各种延续版本）大概是 Windows 和 Android 上用得最多的图形化客户端之一了，界面直观、支持规则分流，新手上手门槛不算高。这篇就当是一份"从零开始"的入门指南。

## 第一步：下载客户端

Clash 系客户端有不少分支版本（早期的 Clash for Windows 已经停止更新，现在常用的是 Clash Verge Rev、Clash Meta 这类延续维护的版本）。建议直接从对应项目的官方发布渠道下载，别在来路不明的网站上随便找安装包——客户端软件涉及你的网络流量，来源可靠性很重要。

## 第二步：拿到你的订阅链接

登录你的机场账号，找到订阅链接（通常在"我的订阅""获取订阅"这类入口）。这个链接本身包含了连接你账号的关键信息，**别随便分享给别人**，就跟你的账号密码一个级别的敏感信息。

不太清楚订阅链接具体是什么、怎么用的，可以先看[这篇](/knowledge/what-is-subscription-link/)。

## 第三步：导入订阅

打开 Clash 客户端，找到"订阅""Profile"这类入口，把复制好的订阅链接粘贴进去，点击导入/更新。稍等几秒，正常情况下客户端会自动拉取节点列表，你应该能在节点列表里看到一堆按地区命名的节点（香港、日本、美国这些）。

如果这一步失败了（提示订阅链接无效、无法连接之类），可以看[订阅链接导入失败怎么办](/troubleshooting/subscription-link-import-failed/)，里面整理了几个常见原因。

## 第四步：选节点，开始使用

节点列表里选一个你想用的地区，点击连接（或者启用系统代理这个开关，不同版本界面表述略有差异）。这时候打开浏览器测试一下，能正常访问就说明配置成功了。

## 关于规则分流，新手要不要研究

Clash 最大的特点之一是支持**规则分流**——让国内网站直连、国外网站走代理，而不是所有流量一股脑塞进代理里。这个具体是怎么回事，可以看[规则集](/glossary/rule-set/)这个词条。

新手阶段不用急着自己写规则，大部分客户端会内置或者让你订阅现成的规则集，直接用默认配置或者社区维护的成熟规则集就是个不错的起点，用一段时间熟悉了再考虑要不要自己微调。

## 常见小问题

**为什么连上了但网页打不开？** 先确认系统代理开关是不是真的打开了，再检查选的节点是不是当前可用（可以在节点列表里测一下延迟，显示超时或者错误的节点先别用）。

**电脑重启后要重新配置吗？** 不用，客户端通常会记住你上次的设置，重新打开就好，除非你手动清除过配置。

**多久需要更新一次订阅？** 建议定期手动点一下"更新订阅"，机场那边节点信息有变动（比如新增/下线节点）时，及时更新能保证你看到的是最新列表。
