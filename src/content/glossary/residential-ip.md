---
term: 住宅IP
definition: 由家庭宽带运营商分配给普通用户的 IP 地址，在网站看来"像一个真实的居家用户"。
extendedExplanation: 和数据中心 IP 相比，住宅 IP 因为看起来更"像正常人"，被网站风控系统标记、限制的概率通常更低，所以在需要解锁流媒体、访问对 IP 类型敏感的服务时，住宅 IP 往往体验更顺畅。
aliases: ["家宽IP"]
relatedTerms: ["datacenter-ip", "exit-ip"]
updatedAt: 2026-09-25
---

机场宣传里说的"原生 IP"，很多时候指的就是住宅 IP（或者至少是"看起来不像数据中心的 IP"）。为什么这东西值钱？因为住宅 IP 资源本身有限——不是随便搭个服务器就能有的，服务商要么自己有住宅带宽资源，要么通过其他方式获取，成本自然比清一色的数据中心 IP 高，这也是为什么带"原生 IP"卖点的套餐，价格通常不便宜。
