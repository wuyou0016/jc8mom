---
term: 出口IP
definition: 你的流量最终"露面"访问目标网站时所使用的 IP 地址，也就是目标网站看到的、真正代表你身份的那个 IP。
extendedExplanation: 出口 IP 是住宅 IP 还是数据中心 IP、属于哪个国家/地区，直接决定了你能不能访问某些地区限定的内容，以及会不会被网站的风控机制盯上。
relatedTerms: ["residential-ip", "datacenter-ip"]
updatedAt: 2026-09-25
---

理解出口 IP 的关键是搞清楚它和"节点所在地"不完全是一回事——有些线路设计比较绕，流量可能经过好几段中转，最终出口的 IP 才是目标网站真正看到的那个。选节点的时候页面上写的地区，通常就是出口 IP 所在地区，这也是为什么"选香港节点"能让你打开"仅限香港地区"的内容。
